# دليل التشغيل داخل GitHub Codespace — تطبيق «صحة رياضية» (SportHealth) v2.1

اتبع الخطوات بالترتيب حرفيًا. انسخ الأوامر والصقها في **الطرفية (Terminal)** داخل الكودسبيس ثم اضغط Enter.

## الخطوة 0: جلب آخر تحديثات المستودع (إلزامي قبل أي بناء)

```bash
git pull origin main
```

## الخطوة 1: تجهيز بيئة البناء (مرة واحدة فقط — 5 إلى 10 دقائق)

```bash
bash yousef/apk-yousef/codespace/setup_android.sh
```

هذا السكربت يثبت تلقائيًا: JDK 17 (حتى لو كان الكودسبيس على Java 25) + Android SDK (API 34) + Gradle 8.7، ويقبل التراخيص، ويحفظ الإعدادات. آمن للتكرار — لو توقف لسبب ما شغّله مرة أخرى وسيكمل من حيث توقف.

> إذا جهّزت البيئة سابقًا (المراحل السابقة) فالخطوة 1 غير لازم — انتقل مباشرة للخطوة 2.

## الخطوة 2: بناء التطبيق

```bash
bash yousef/apk-yousef/codespace/build_apk.sh
```

- **أول مرة**: 15–25 دقيقة (تنزيل مكتبات Compose وRoom وWorkManager وGradle).
- **المرات التالية**: 2–5 دقائق.
- عند النجاح يظهر: `✓ تم بناء التطبيق بنجاح!`
- **الناتج**: `yousef/apk-yousef/apk_output/SportHealth-v2.1-debug.apk`

## الخطوة 3: نقل APK إلى هاتفك

كليك يمين على الملف
`yousef/apk-yousef/apk_output/SportHealth-v2.1-debug.apk`
في مستكشف ملفات VS Code (الشريط الجانبي) ← **Download**.

> ملاحظة: ملفات APK **لا تدخل المستودع** (مجلد apk_output يبقى فارغًا في المستودع) — كل إصدار يُبنى في الكودسبيس ويُنقل مباشرة للهاتف.

## الخطوة 4: التثبيت على الهاتف

1. افتح الملف المحمّل من إشعارات الهاتف أو تطبيق «الملفات».
2. اسمح بـ«التثبيت من مصادر غير معروفة» لهذا الملف.
3. ستُحدَّث النسخ السابقة فوقها مباشرة دون فقدان أي بيانات (نفس حزمة التطبيق، الإصدار 21 أعلى من 2 و1).
4. اسم التطبيق في قائمة الهاتف أصبح **«صحة رياضية»**.

## ما الجديد في النسخة 2.1 (التطبيق المكتمل)؟

| الميزة | أين تجدها |
|---|---|
| تسجيل قياس اليوم (mg/dL، مدى 40–600، تحذير القيم الشاذة) | صفحة المريض ← زر «تسجيل قياس اليوم» |
| التقويم الشهري الملون + تسجيل الأيام الفائتة وتعديلها | صفحة المريض |
| انتقال الحالة تلقائيًا: قيد الإنشاء → جاري (مع أول قياس) → مكتمل (زر «إنهاء وتجميع النتائج») | صفحة المشروع |
| قياسات اليوم المعلقة: قائمة الناقصين مع تسجيل سريع | صفحة المشروع أو بطاقة اليوم في الرئيسية |
| التنبيه اليومي 20:00 بعدد الناقص + تغيير الساعة (19/20/21) + إذن الإشعارات | الأدوات والإعدادات |
| النتائج: مخطط مريض خطي (معيّن مفرغ = قيمة معوضة، نطاق 70–130، خط اتجاه) | صفحة المشروع ← «النتائج والمخططات» |
| لوحة جاهزية الفحص (✓/✗ لكل مريض وسبب الرفض حرفيًا كما في المتطلبات) | أعلى شاشة النتائج |
| الإحصاءات حسب الفئة: منحنى التغير النسبي، أعمدة، توزيع الحالة، بطاقات الملخص، مقارنة الفئتين | قائمة الفئة في شاشة النتائج |
| الجدول الأسبوعي mean±SD | أسفل شاشة النتائج |
| تصدير CSV (UTF-8+BOM أعمدة إنجليزية لـ Excel/SPSS) + تقرير PDF عربي + مشاركة الملخص | أسفل شاشة النتائج |
| الوضع التجريبي المعزول: 3 نماذج مرفقة أو ملف .db من الهاتف، شريط تحذير دائم، خروج يمسح الحاوية | «عرض نموذج تجريبي» في الرئيسية |
| نسخة احتياطية كاملة لقاعدة البيانات | الأدوات والإعدادات |

## حل المشاكل

| المشكلة | الحل |
|---|---|
| رسالة `gradle-8.7: command not found` أثناء التجهيز | نسخة قديمة من السكربت. اكتب `git pull origin main` ثم أعد تشغيل السكربت |
| خطأ `Unsupported class file major version 69` أو فشل بسبب Java 25 | السكربت المحدّث يثبّت JDK 17 ويختاره تلقائيًا — `git pull origin main` ثم أعد `setup_android.sh` |
| `git pull` يقول تعارضات محلية | اكتب `git checkout . && git pull origin main` |
| فشل البناء برسالة طويلة | انسخ آخر 20 سطرًا من الخطأ وأرسلها في المحادثة |
| الكودسبيس توقف/أغلق | أعده من github.com/codespaces ثم أعد الخطوة 2 (البيئة محفوظة) |
| انتهت المساحة | اكتب `df -h ~` وأرسل الناتج |
| تطبيقان متشابهان على الهاتف | هذه نسخة أعلى من نفس الحزمة `com.yousef.stephealth` — التثبيت يحدّث فوق القديم ولا ينشئ تطبيقًا ثانيًا |
