# دليل التشغيل داخل GitHub Codespace — تطبيق «خطوة صحية»

اتبع الخطوات بالترتيب حرفيًا. انسخ الأوامر والصقها في **الطرفية (Terminal)** داخل الكودسبيس ثم اضغط Enter.

## الخطوة 0: جلب آخر تحديثات المستودع (إلزامي — لأن مجلد apk-yousef أُضيف بعد إنشاء الكودسبيس)

```bash
git pull origin main
```

## الخطوة 1: تجهيز بيئة البناء (مرة واحدة فقط — 5 إلى 10 دقائق)

```bash
bash yousef/apk-yousef/codespace/setup_android.sh
```

هذا السكربت يثبت تلقائيًا: Java 17 + Android SDK (API 34) + Gradle 8.7، ويقبل التراخيص، ويحفظ الإعدادات. آمن للتكرار — لو توقف لسبب ما شغّله مرة أخرى وسيكمل من حيث توقف.

## الخطوة 2: بناء التطبيق (كل مرة تريد نسخة جديدة)

```bash
bash yousef/apk-yousef/codespace/build_apk.sh
```

- **أول مرة**: 15–25 دقيقة (تنزيل مكتبات Compose وRoom وGradle).
- **المرات التالية**: 2–5 دقائق.
- عند النجاح يظهر: `✓ تم بناء التطبيق بنجاح!`

## الخطوة 3: نقل APK إلى هاتفك

**الطريقة المعتمدة**: كليك يمين على الملف
`yousef/apk-yousef/apk_output/StepHealth-v0.2-debug.apk`
في مستكشف ملفات VS Code (الشريط الجانبي) ← **Download**.

> ملاحظة: ملفات APK **لا تدخل المستودع** من هذه المرحلة فصاعدًا (حمايةً من التعارضات وحجم المستودع) — كل إصدار يُبنى محليًا في الكودسبيس ويُنقل مباشرة للهاتف.

## الخطوة 4: التثبيت على الهاتف

1. افتح الملف المحمّل من إشعارات الهاتف أو تطبيق «الملفات».
2. سيظهر تنبيه «التثبيت من مصادر غير معروفة» — اسمح به لهذا الملف.
3. إذا كانت النسخة 0.1 مثبتة لديك فستُحدّث فوقها مباشرة دون فقدان أي شيء (التطبيق يُثبّت كإصدار جديد أعلى).
4. سترى الشاشة الرئيسية، ومع المرحلة 2: أنشئ مشروعًا فيُحفظ **فعليًا** حتى بعد إغلاق التطبيق، ثم جرّب معالج إضافة المرضى سبع الخطوات وقائمة المرضى والحذف بتأكيد مزدوج.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| رسالة `gradle-8.7: command not found` أثناء التجهيز | كانت في نسخة قديمة من السكربت (خطأ سطر العرض فقط — Gradle نفسه كان يُثبَّت). اكتب `git pull origin main` ثم أعد تشغيل السكربت |
| خطأ `Unsupported class file major version 69` أو فشل البناء بسبب Java 25 | Codespace يأتي بـ Java 25 وGradle 8.7 يحتاج 17–21. السكربت المحدّث يكتشف ذلك ويثبّت JDK 17 ويختاره تلقائيًا — اكتب `git pull origin main` ثم أعد تشغيل `setup_android.sh` |
| `git pull` يقول تعارضات محلية | اكتب `git checkout . && git pull origin main` |
| فشل البناء برسالة طويلة | انسخ آخر 20 سطرًا من الخطأ وأرسلها لي في المحادثة |
| الكودسبيس توقف/أغلق | أعده للتشغيل من github.com/codespaces ثم أعد الخطوة 2 (البيئة محفوظة) |
| انتهت المساحة | اكتب `df -h ~` وأرسل لي الناتج |
